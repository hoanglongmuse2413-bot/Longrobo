# Long Robot - App riêng của bạn
Hướng dẫn build APK không cần tải file zip, làm 100% trên điện thoại.

## Cách làm (3 phút)
1. Tạo repo mới trên GitHub tên `long-robot` (Public)
2. Bấm `Add file` > `Create new file`
3. DÁN ĐƯỜNG DẪN ở trên (ví dụ: app/src/main/AndroidManifest.xml) vào ô tên file
4. DÁN NỘI DUNG ở dưới vào ô code
5. Bấm `Commit changes` màu xanh
6. Lặp lại cho hết 11 file bên dưới
7. Vào tab `Actions` > Chọn `Build APK` > Bấm `Run workflow` > Đợi 3-5 phút là có APK để tải về

Không cần Android Studio, không cần máy tính!
Build xong vào Actions > Artifacts > Tải file Long-Robot-APK về cài là xong.
